五轴机床数字孪生监测 传感采集 · 上云 · 孪生

校内实验室项目（参与）：机床故障监测与数字孪生系统。负责传感器采集与数据交互、Flask 后端搭建， 打通「机床传感器 → MQTT → 华为云 IoTDA → 后端 → React 数字孪生前端」全链路。

传感器采集MQTT华为云 IoTDA FlaskReactAPS 数字孪生
时间 2024.02 – 2024.12 负责部分 传感器采集与数据交互 · Flask 后端 算法 ANFIS + LSTM 故障检测

$ 项目内容 content/

项目初期调研机床故障监测技术，发现可通过主轴功率波动监测撞刀故障并及时切断电源保护机床。 采集大量主轴功率数据与撞刀故障数据，清洗后先用 ANFIS 训练故障检测模型，后加入 LSTM 引入时间维度， 提高预测准确率。

  • 物联网采集：在机床上部署传感器采集主轴功率、主轴温度，通过伺服电机编码器获取电机转速，经 MQTT 上传华为云 IoTDA 平台，再由数据转发到自建监控平台后端；
  • 后端：Flask 搭建数据监控平台后端；
  • 数字孪生（React 前端）：接入 AutoDesk APS 平台——电机温度 / 主轴温度超阈值时在模型上高亮并弹窗警告（热图警告）；采集处理伺服编码器运动数据，接入 APS 模型运动接口实现机床运动同步；
  • AI 应用：把机床故障维修手册、性能参数、运维文献转化为 2000 条问答数据集，微调大模型后接入故障检测平台，运维人员遇到故障可快速获取维修方法。
