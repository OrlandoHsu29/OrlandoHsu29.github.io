AI 健康管家 智能体 + RAG · 实习项目

广东延康科技有限公司技术部 · AI 应用开发实习（2025.01 – 2025.09）。 基于 Dify 搭建健康咨询智能体：3 个 Sub-Agent 集成 Main Agent，对话中自动沉淀结构化健康档案， 通过针对性 RAG 检索提供个性化健康咨询，并负责本地大模型部署与端侧智能体封装。

实习项目DifyRAG 多 Sub-AgentFlaskVLLM / Ktransformers
时间 2025.01 – 2025.09 落地 微信小程序 + 公司 APP 技术栈 Python (Flask) · Dify · RAG

$ 智能体架构 agent/

搭建了 3 个 Sub-Agent（文件处理 / 自动对话总结 / 个人健康档案检索）并集成到一个 Main Agent，实现：

  1. 信息提取与存储：对话中自动把用户提及的健康状况、影响健康的活动总结成结构化文本存入 RAG；
  2. 数据绑定：用元数据标注把数据与用户绑定；
  3. 个性化检索：每次对话检索时，RAG 只召回属于该用户的健康档案，实现长期记忆与精准召回。

工作流基于 Dify 图形化搭建，本质逻辑与 LangChain 一致；同时负责将智能体接入后端，已在微信小程序和公司 APP 上跑通。

$ 本地模型部署与收获 notes/

  • 通过 ModelScope / HuggingFace 拉取大模型，基于 VLLM / Ktransformers 等框架本地部署测试，将符合需求的小参数模型接入 Dify 做端侧智能体开发与封装；
  • 2025 上半年就接触到 Claude Code / Agent 辅助开发，较大多数人提前约一年将 AI 用于工程实践，对 AI 技术路线与开发框架形成系统认知。
