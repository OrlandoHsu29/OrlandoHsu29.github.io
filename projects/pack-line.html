1. 焊接模块开发 · 负责人

项目背景 background/

产线焊接环节原焊接机只能焊接固定规格的锂电池组，无法满足定制化生产需求。 因此自研三轴锂电组焊接机 + 视觉定位系统，实现柔性化自动焊接：传送带把电池组送到摄像头下方 → 拍照识别焊点位置 → 驱动焊接头移动到焊点 → 下降 Z 轴点焊 → 传送带运行、传来下一组。 接手时该环节还是 demo（MATLAB 通用视觉算法 + G 代码控制 Mach3），历时约一年完成成熟方案重构（OpenCV 工业视觉 + PLC 控制 + Unity 数字孪生）。

柔性焊接视觉开发 vision/

  1. 基于 OpenCV 搭建柔性焊接视觉识别流程：图像预处理 → 霍夫圆变换识别定位焊接点 → S 型路径排序焊接坐标 → 坐标变换 → 格式化指令并下发到 PLC 驱动步进电机，打通柔性焊接控制闭环；
  2. 结合焊接机与传送带运动参数建立数学模型预测焊接点位，在电池组输送过程中跟随焊接，减少停机时间、提高产能。

数字化与品质追溯 digital/

  1. 搭建 Unity 数字孪生平台并打通 PLC 通讯，实现设备运行状况实时映射与撞机告警；
  2. 采集不同焊接质量的电池组图像进行图像标注并训练图像分类模型，判定焊接质量优劣，辅助良率判定与异常处理（ModelArts）。

2. 贴纸模块结构设计 · 机械设计

① 电池移料机构设计 mechanism/

调研市面上现有的圆柱形锂电池移料机构，通过 Fusion 360 重新设计建模： 将非标件替换为标准件以降低成本，并调整参考机构的结构以适配产线需求。

② 机架与钣金结构设计 structure/

完成贴青稞纸机构机架的建模与结构设计：钣金设计与铝型材框架搭建， 并完成末端执行机构与控制设备的机械连接与固定，确保整体机械系统的稳定性与装配精度。

3. 产线整合 · BOM 与 PLC 控制

BOM 整理 bom/

对接产线各模块，确定电气设备、架构铝材的选型与数量，整理形成 BOM 表， 输出标准化清单，支撑采购与装配。

PLC 控制架构与工业组网 plc/

负责生产线的设备统计与整合：对接各模块控制需求，确定 PLC、触摸屏、交换机等电气设备的数量与选型， 设计 PLC 控制架构，制定工业组网及硬件部署方案，推动产线顺利落地。
